## Γιατί βγήκε αυτή η έκδοση

Το εργαλείο είναι ελληνικό — αλλά το αποθετήριο το βλέπει όλος ο κόσμος. Ως τώρα, όποιος δεν
διάβαζε ελληνικά δεν καταλάβαινε ούτε τι κάνει το εργαλείο ούτε σε τι χρησιμεύει. Η v5.7 το λύνει:
**το README και η εισαγωγή της εφαρμογής μιλούν πλέον αγγλικά**, χωρίς να αλλάξει τίποτε στη
διεπαφή ή στα prompts, που παραμένουν ελληνικά γιατί το εργαλείο είναι φτιαγμένο για ελληνικά
κείμενα.
